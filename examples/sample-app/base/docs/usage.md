# Use itemctl

## List items

```sh
python app.py list [--max N]
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--max` | `10` | Maximum items to show |

## Environment variables

| Variable | Default | Description |
| -------- | ------- | ----------- |
| `ITEMCTL_API_URL` | `http://localhost:8000` | Base URL of the inventory service |
